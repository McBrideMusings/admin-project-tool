# ADR-0008: Manifest validation errors share one type, `validate.Error`

Every "is this command or action well-formed" failure is a `*validate.Error` (`internal/validate`), whichever package found it. `internal/validate` owns the command-routing, key, footer and `[terminal]` checks; packages that own other knowledge (`internal/frame`'s URL and footer references, `internal/guards`, `internal/kinds`) return their own errors, and `validate.Wrap` tags them. `admin check` joins every problem with `errors.Join`, and a caller tells a malformed manifest from any other failure with `errors.As`. `internal/validate` imports no internal package except the leaf `internal/keymap`, so `internal/manifest` can call it without an import cycle.
